# Networking

The human half of the search. **Every interview so far came from a person, not an application portal**, so this folder gets worked first.

- [[Outreach Tracker]] — everyone worth contacting, tiered, with the last touch and the next step.

## The rules for outreach
- **Warm before cold.** An introduction beats a cold message every time. Ask for one before sending one.
- **One follow-up, then wait.** A second unanswered message is fine; a third is noise.
- **Log every touch the same day** in the tracker, or it didn't happen.
