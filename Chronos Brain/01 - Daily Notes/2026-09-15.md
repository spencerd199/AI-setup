## Session 1 — 8:45 AM: Job-finder run caught failing silently

### What Got Done
- Morning boot flagged a `FAILED` row in `job-finder/run-log.md` from 8:00 AM. The scheduler itself reported success.
- Read the run's transcript instead of guessing. The firm-list note had been renamed from a file browser last week, outside Obsidian, so the `Target Companies` link in the job's `SKILL.md` no longer resolved. The agent couldn't find the firm list, said so, skipped the completion token, and exited 0.
- **This is the design working:** exit code 0 means "the process ended," not "the work happened." The missing token is what turned a silent failure into a logged one.
- Renamed the note back inside Obsidian, searched the vault for every reference to the wrong name (two found, both fixed), and re-ran the job by hand. It completed and printed its token.

### Decisions Made
- Renames happen inside Obsidian only, which is already a rule in `VAULT-INDEX.md`. The failure came from breaking it, so no new rule is needed.
