# Pricing Model

## The ladder
| Listing | Price | Role |
|---|---|---|
| Single print | $4.99 | The entry point — and the anchor that makes a set look like a deal |
| Set of 3 | $9 | Mid tier |
| Set of 6 | $14 | The best value per print, and the one most buyers choose |

**The single exists to make the set the obvious choice.** Removing it would lower revenue, not raise it.

## No launch discount
A first-purchase discount trains buyers to wait for the next one. **Raised once and declined.** Revisit only if the catalogue passes 60 listings.

## Taxes
Set aside 25% of net shop income each month. Quarterly estimated payments are tracked on [[Active Priorities]] with their due dates.
