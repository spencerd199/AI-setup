# Ideas

Venture thinking: one scored ledger, one graveyard, and a workspace file per thinking session.

- [[Idea Ledger]] — every live idea with its score, and every killed idea with the reason. **The graveyard is the more useful half.**
- **`Sessions/`** — one workspace file per thinking session, created from [[Session Template]].
  - [[Session 3 - 2026-09-15]] — the most recent: the meal-planning template pack survived a kill attempt.

## How the sessions work
**Mon / Wed / Fri are generative** — new territory, wide, nothing judged. **Tue / Thu are convergent** — take the strongest live idea and try to kill it.

Each session starts with four prepared items: a **territory** to explore, a **friction** from the actual week (quoted from recent daily notes), **what changed** in the tools recently, and a **pre-check** on who already sells the strongest idea. **The pre-check is the cheapest step and it has killed more ideas than any other.**

**The core test every idea is scored against:** does it own something that earns without Spencer's time? An idea that sells hours is a job, not a business.
